# Jeffrey's Games

A small static site for two Unity games — a parkour game and a horror game —
with screenshots, download links, and a video showing how to install them.

Six hand-written HTML pages, no framework and no build step. Open `index.html`
to view it locally.

```
index.html        home
ParkourGame.html  parkour game page
HorrorGame.html   horror game page
Downloads.html    download links, with HowToDownload.mp4 embedded
About.html
Sources.html      credits for assets used in the games
Images/           screenshots and page art
```

This is one of my earliest projects and is kept as it was, apart from repairs
to links that pointed at files that were not there.
